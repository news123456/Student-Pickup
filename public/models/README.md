# AI Models

This directory holds the face-api models.
To make the application fully offline, please copy the required face-api model files 
(e.g., face_landmark_68_model-weights_manifest.json, tiny_face_detector_model-weights_manifest.json, etc.)
from https://github.com/vladmandic/face-api/tree/master/model into this directory.

Ensure the files are named exactly as expected by the face-api.
